# Literature boundary

This repository does **not** claim novelty.

The current working boundary from the discovery phase is:

- McTague's principal result addresses a `p ≡ 1 (mod q)` branch; a later same-residue weakening uses a size hypothesis `p > q`. The example `v_2(gcd {binom(6,3k)}) = 2` records the obstruction when that size condition is dropped.
- Wu (2026) gives computable formulas under hypotheses involving prime-power moduli and relevant primes congruent to `1 mod m`; it does not presently appear to settle the `-1 mod m` branch targeted here.
- Nearby work also treats consecutive blocks, coprimality restrictions, central intervals, or conditions such as `gcd(N,k)=d`, rather than this exact restricted family.

Before any publication-level novelty statement, run a dedicated literature review with complete bibliographic data and verify the scope of each comparison directly from the source.
